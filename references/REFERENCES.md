## Recurring patterns (what to build from)

**Composition**
- One giant wordmark or headline, often *behind* the device mockup (01, 02, 08, 11, 13, 18)
- Device mockups (phone in hand, tilted phones, laptop) as the hero object
- Floating UI fragments around the device: chips, notification cards, chat bubbles, cursors with labels (01, 10, 11, 18, 21)
- Metadata in the corners: role tags top-left, year top-right, e.g. "UX / UI", "Research", "2026" (02, 08, 15, 18, 21)

**Type**
- Heavy geometric/grotesk sans for display, set very large with tight tracking
- One alternate: thin oversized lowercase (04) or outlined/ghosted (02, 13)

**Colour**: three families recur
1. Dark: near-black + lime/violet accents (05, 15, 18)
2. Sky blue / cobalt with white type (06, 11, 13, 19, 20, 21)
3. Lavender/pink soft gradients (01, 08, 10)

**Details**
- Pill-shaped tags everywhere (filled or outlined, sometimes rotated)
- Sparkle/star glyphs, hand-drawn arrows and squiggles
- 3D glossy or soft-textured objects and friendly mascots with googly eyes (03, 07, 09, 16, 19, 21)
- Glassmorphism: blurred, frosted floating cards

## Implications for the portfolio site
- Project grid of 4:3 cover cards (these are all 808×632), each with its own bold colour world
- Case-study page hero: big title + device mockup + floating chips + tag/year metadata
- Site chrome stays neutral (dark or off-white) so each project cover can carry the colour
- Motion: floating chips with gentle parallax/drift, hover tilt on cards
